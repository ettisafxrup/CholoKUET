Find your way
around KUET.

CholoKUET is an offline campus navigator. Say where you are and where you're going, and it tells you the roads to take, where to turn, what you'll pass and how long the walk is. Every feature runs on a data structure we wrote ourselves.

Features

        

          Everything you need to get around.
        

        

          Eleven menus for students and four more for admins. Type a place by
          part of its name, its number on the map, or raw coordinates.
        


        

      

    


    
    

      

        

          
System design

          

            Three clean layers. No shortcuts.
          

          

            The menus only talk to the user, the campus model is the only code
            that touches files, and the data structures know nothing about
            either. That is why each one can be opened, explained and tested on
            its own.
          

          
    
            
  • 
              Hand-written Stack and Queue. No
                std::stack, std::queue or
                std::sort anywhere;
                make check-manual proves it.
            
    • 
            
  • 
              Real coordinates. 38 places from OpenStreetMap, 6 fitted
                from the KUET master plan (about 27 m average error).
            
    • 
            
  • 
              Never crashes on bad input. Strict parsing, safe menus,
                and every action written to an activity log.
            
    • 
            
  • 
              Portable. One static .exe with its own icon
                that runs on any Windows PC.
            
    • 
          

        

        

          

            LAYER 1 · MENUSNavigator
            

              Login, main menu, trips, places, admin tools. Talks to the user
              only.
            

          

          

            LAYER 2 · MODELCampus
            

              Places (array), categories and the walkway graph. Loads, validates
              and saves every data file.
            

          

          

            LAYER 3 · COREStack · Queue · Graph · Tree · Search · Sort · Trip
            

              BFS on our queue, DFS on our stack, Haversine distances and
              turn-by-turn planning.
            

          

          

            STORAGEdata/*.txt · logs/application.log
            
Plain text you can read, edit by hand and track in Git.

          

        

      

    


    
    

      

        
Data structure playground

        

          Built by hand. Try them yourself.
        

        

          These behave like dsa/stack and dsa/queue,
          shrunk to 8 slots so you can hit overflow, underflow and wraparound.
        


        

          

            
Stack · LIFO

            

              An array and one index, top. Used for DFS, the Back
              button and reversing BFS routes.
            

            

            
top = -1 (empty)

            

              
              
              
            

          

          

            
Circular queue · FIFO

            

              Both ends wrap round with % CAPACITY, so freed slots
              are reused. Powers BFS.
            

            

              
            

            

              front = 0, rear = -1, count = 0

Get started

        

          Up and running in a minute.
        

        

          All you need is g++ with C++17. On Windows, install it through MSYS2.
        

        

          

            
01

            
Install g++

            

              pacman -S
              mingw-w64-ucrt-x86_64-gcc
              # then add C:\msys64\ucrt64\bin to PATH
            

          

          

            
02

            
Build and run

            

              make run
              # or, without make:
              g++ -std=c++17 main.cpp -o CholoKUET
            

          

          

            
03

            
Run the tests

            

              make test make check-manual
